Клас Calculator (ООП)

Реалізація методів add, subtract, multiply, divide та збереження результату в полі this.result.

0

Тестовий запуск методів класу (з коду lesson18.js):

  • calc.displayResult(); // Початковий: 0
  • calc.add(10, 5); // 15
  • calc.add(5); // 15 + 5 = 20
  • calc.subtract(8); // 20 - 8 = 12
  • calc.multiply(3); // 12 * 3 = 36
  • calc.divide(6); // 36 / 6 = 6

Всі операції успішно виконуються також і у консолі браузера (F12).
