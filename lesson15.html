4 Множення числових властивостей на 2

Функція multiplyNumeric(obj) подвоює числа і не змінює рядки (наприклад, title)

До виклику:

{
  width: 200,
  height: 300,
  title: "Моє меню"
}

Після multiplyNumeric():

{
  width: 400,
  height: 600,
  title: "Моє меню"
}
Числові поля width та height успішно подвоєно!
